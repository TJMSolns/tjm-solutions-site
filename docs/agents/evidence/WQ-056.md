# Evidence — WQ-056

**Item:** Fix live WCAG2AA contrast failures in syntax-highlighted code, both themes. WQ-056's row
named 4 failing light-theme prism tokens (233 errors across 7 pages) and 1 failing dark-theme token
(5 errors across 3 pages), root cause undiagnosed.

**Root cause:** `docusaurus.config.ts` used `prism-react-renderer`'s stock `themes.github` (light) and
`themes.dracula` (dark) unmodified. Both ship token colors that were never checked against this site's
actual code-block backgrounds (`#f6f8fa` light, `#282a36` dark) for 4.5:1 contrast.

**Fix:** `src/prismTheme.ts` (new file) derives `lightCodeTheme`/`darkCodeTheme` from the stock themes,
overriding only the failing token colors' hex/rgb values (hue preserved, lightness adjusted), computed
via the standard WCAG relative-luminance formula. `docusaurus.config.ts` now imports these instead of
`prismThemes.github`/`prismThemes.dracula` directly. No swizzle (POL-001 compliant, config-level change
only).

**Scope correction found during the fix:** a 5th light-theme token, `function`/`deleted`/`tag`
(`#d73a49`, 4.30:1), was not in WQ-056's original 4-token diagnosis. Found while computing fixes for the
other four, by checking every token in `themes.github.styles` against the background, not just the ones
already named. Fixed alongside the other four; see `src/prismTheme.ts`'s table for all 6 before/after
ratios (4.52–4.59 after, all with a small margin above 4.5, not exactly at the line).
