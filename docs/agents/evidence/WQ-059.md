**Item:** `.claude/hooks/pretooluse-done-gate.py` fails on any edit outside this repo, blocking the
Edit tool on cross-repo writes.

**Root cause:** not inside the Python script. `.claude/settings.json` invoked six hooks with a bare
relative path (`.claude/hooks/session-start.sh`, `.claude/hooks/source-edit-check.sh` twice,
`.claude/hooks/pretooluse-done-gate.py`, `.claude/hooks/session-stop.sh`,
`.claude/hooks/stop-git-durability-gate.py`), resolved by the shell against whatever the current
working directory happens to be at invocation time. A seventh hook,
`pretooluse-crontab-remotetrigger-gate.py`, already used the correct pattern:
`${CLAUDE_PROJECT_DIR}/.claude/hooks/...`, an absolute path anchored to the project root regardless of
CWD. Confirmed by diffing this project's `settings.json` against harness-evolution's canonical copy
(`/home/tjm/Cloud/GitHub/harness-evolution/.claude/settings.json`), which uses `${CLAUDE_PROJECT_DIR}`
for every hook command.

**Fix:** the six bare-relative commands now use `${CLAUDE_PROJECT_DIR}/.claude/hooks/...`, matching the
already-correct seventh. Nothing else in `settings.json` changed: permissions, the ts/tsx-only
typecheck hook, the wcag Stop reminder, and the secrets-snitch hooks are all local to this project
(absent from harness-evolution's copy entirely) and were left untouched.
