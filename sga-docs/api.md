# API reference

The Scaladoc for every public type and function in `sga` is generated from the source on each release.

**[Open the API reference](pathname:///sga/api/index.html)**

Start with `solutions.tjm.sga` for the engine (`GeneticAlgorithm`, `run`, `Selector`, `Crossover`, `Mutation`, `Replacement`, `Termination`, `Rand`), then `solutions.tjm.sga.ml` for fitness functions and the non-GA feature-selection techniques.
