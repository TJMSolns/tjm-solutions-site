object Mahalanobis

True Mahalanobis distance — the natural upgrade Outliers.scores' own docstring names as unbuilt: accounts for real correlation between features via the actual inverse covariance matrix, rather than Outliers' independence-assuming approximation (scale each feature separately, take the Euclidean norm). No new inversion algorithm needed — linalg.Inversion.invertSymmetric (built for this) reuses Pca's own eigendecomposition machinery.

True Mahalanobis distance — the natural upgrade Outliers.scores' own docstring names as unbuilt: accounts for real correlation between features via the actual inverse covariance matrix, rather than Outliers' independence-assuming approximation (scale each feature separately, take the Euclidean norm). No new inversion algorithm needed — linalg.Inversion.invertSymmetric (built for this) reuses Pca's own eigendecomposition machinery.

Rand[Vector[Double]], not a plain Vector[Double] like Outliers.scores — inverting via eigendecomposition needs Rand's power-iteration machinery. Left to the caller to seed, not fixed internally the way Pcknn's PCA usage is: outlier marking is a one-off diagnostic step, not a repeated fitness evaluation needing a reproducible seed across many calls.

Real finding, not the originally expected one — verified against real Iris data, not assumed: this does NOT meaningfully reduce Iris's over-flagging rate versus Outliers.scores' approximation (17.33% vs. 16%, nearly identical at a comparable threshold). Mahalanobis measures violation of a dataset's own correlation STRUCTURE — a genuinely different question than raw distance-from- center, demonstrated directly in MahalanobisSuite — not a strict improvement on Outliers' flagging RATE. Don't expect fewer flags from switching to this; expect different points to be the ones flagged when features are meaningfully correlated.

Real, known limitation, not solved here: a zero-variance feature (or any exact linear dependency among features) makes the covariance matrix singular — an eigenvalue of exactly 0, dividing by zero in the inverse. Scaling/Outliers both have an explicit total- function fix for the zero-variance case; this does not yet.

object SpectralResampling

Resamples a raw (x, y) curve (a spectrum's real, unevenly-spaced measurement points) onto a fixed grid via linear interpolation — the step RawRow.toDataset's fixed-feature-column shape needs before a continuous spectral curve (RRUFF's Raman data) can become a Dataset row at all. A grid point outside a spectrum's own real coverage is flagged (None), never extrapolated or silently padded — the same "marking, not scrubbing" discipline Outliers already uses, applied here to missing coverage instead of outlying values.

def bin(thresholds: Vector[Double])(value: Double): Int

Threshold bucketing — sga had independently reimplemented this exact pattern twice (Wine Quality's 3-bucket re-binning, RRUFF's spectral-resampling grid design) with no shared utility, the anti-pattern Smith, "Machine Learning Systems", Ch4 names directly.

Threshold bucketing — sga had independently reimplemented this exact pattern twice (Wine Quality's 3-bucket re-binning, RRUFF's spectral-resampling grid design) with no shared utility, the anti-pattern Smith, "Machine Learning Systems", Ch4 names directly.

thresholds must be sorted ascending (a caller precondition, not checked — same posture as Distance/Rand.chance's own unenforced-but-documented preconditions elsewhere in this codebase). Bucket i is (thresholds(i-1), thresholds(i)]; bucket 0 is everything at or below thresholds(0); the last bucket is everything above the last threshold.
