Dataset

solutions.tjm.sga.data.Dataset
See theDataset companion object
final case class Dataset[L](samples: Vector[Sample[L]])

The fixed collection of real samples Fitness evaluates a genome against. Not a Population: Population is the evolving set of candidate genomes; Dataset never changes across generations.

Enforces one real structural invariant once, rather than trusting every caller to keep feature vectors aligned — same move as Matrix checking dimension conformance up front.
