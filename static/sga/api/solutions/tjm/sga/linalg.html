object Inversion

Matrix inversion via eigendecomposition — no general-purpose inversion algorithm (Gauss-Jordan, LU) needed; topEigenvectors/ rayleighQuotient (already built for Pca) invert a SYMMETRIC matrix for free: M = V diag(lambda) V^T implies M^-1 = V diag(1/lambda) V^T. Only correct for symmetric matrices — the one caller this exists for, Mahalanobis, only ever inverts a covariance matrix, which is always symmetric by construction.

def dominantEigenvector(m: Matrix, iterations: Int): () => Vector[Double]

The dominant (largest-eigenvalue) unit eigenvector of a symmetric matrix, via power iteration from a random starting vector.

The dominant (largest-eigenvalue) unit eigenvector of a symmetric matrix, via power iteration from a random starting vector.

The starting vector must be random, not a fixed constant: a fixed vector can land exactly in — or exactly orthogonal to — an eigenspace for a symmetric or adversarial input, which silently breaks convergence (see topEigenvectors, which found this the hard way). A random start makes that a probability-zero event instead.

def normalCdf(x: Double): Double

The standard normal cumulative distribution function — needed to turn a z-score (Boruta's own binomial-proportion test statistic) into a real p-value for Benjamini-Hochberg multiple-testing correction (Godsey, "Think Like a Data Scientist", Ch7): the BH procedure operates on p-values, not raw z-scores.

The standard normal cumulative distribution function — needed to turn a z-score (Boruta's own binomial-proportion test statistic) into a real p-value for Benjamini-Hochberg multiple-testing correction (Godsey, "Think Like a Data Scientist", Ch7): the BH procedure operates on p-values, not raw z-scores.

Abramowitz & Stegun formula 26.2.17 — a standard, widely-cited rational approximation, accurate to ~7.5e-8 for any real x. Not an exact closed form (the normal CDF has none), but real, checkable numerical analysis, not a guess — verified against known values (Φ(0)=0.5, Φ(1.96)≈0.975) rather than trusted blind.
