final case class ClassMetrics(precision: Double, recall: Double, fMeasure: Double)

Per-class precision/recall/F-measure — Classification. leaveOneOutAccuracy reports raw accuracy only, which genuinely misleads on real, already-in-repo imbalanced data (Glass, Wine Quality): a majority-class-only classifier can score deceptively well on accuracy alone while a minority class's real recall is zero. A reporting-layer addition alongside leaveOneOutAccuracy, same "rendering, not new architecture" shape as data.Descriptive (Smith, "Machine Learning Systems", Ch6).

object NaiveBayes

Gaussian Naive Bayes — sga's second Classification-compatible classifier alongside Knn (Smith, "Machine Learning Systems" Ch5, item 4): assumes conditional feature independence given the class, models each feature within each class as a 1D Gaussian (population mean/ variance — same convention data.Descriptive already uses), and picks the class maximizing prior * likelihood, in log-space to avoid underflow across many features. Same "no separate fit step exposed" calling shape as Knn.classify — training is a plain Dataset argument recomputed each call, not a cached model object; a genuine diversification in METHOD, not in calling convention.
