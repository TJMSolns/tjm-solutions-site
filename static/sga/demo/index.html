sga Run Viewer

Reads the JSON a genetic-algorithm run exports — nothing is computed here, only plotted.

Load a run

Look at a real run, or drop in a JSON file exported by sga (Cli.toJson).

Expects {seed, populationSize, generationsRun, bestFitness, selectedFeatures, fitnessTrajectory} — sga's real, current CLI export shape. An optional pcProjection: [[pc1, pc2, label], …] array is also read, if present, for the PC scatter panel below (Cli.toJson fills it in when given the dataset).

Fitness trajectory

Best fitness in each generation. The engine isn't elitist, so a generation can lose the best genome found so far; the best ever is the figure above.
